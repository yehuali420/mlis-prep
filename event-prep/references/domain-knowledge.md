# 天文领域知识库｜术语卡、中法交流礼仪与英文表达

> 用途：为天文科普、展位讲解和国际交流提供基础术语参考。此文件是通用知识，不证明任何机构参与本次活动，也不证明某项观测或科研成果已经发生。涉及具体目标、观测数据、项目成员、机构合作或成果时，必须另附官方来源。

## 1. 天文术语卡

| 中文术语 | 英文 | 简明解释 | 使用边界/防误用 |
|---|---|---|---|
| 掩星 | stellar occultation / occultation | 前景天体从观测者视线方向经过背景恒星前方，使恒星光度短时下降；可通过光变记录研究前景天体的尺寸、形状或周围结构等 | 需区分预测、观测记录与分析结论；不能仅凭术语推断本次活动开展了该观测 |
| 小行星掩星 | asteroid occultation | 小行星遮挡背景恒星的掩星事件 | 事件时间、路径、目标和结果须引用可靠预测或正式观测报告 |
| 互掩 | mutual occultation / mutual event | 在相互绕转的天体系统中，一个天体从视线方向遮挡另一个天体；具体语境也可能涉及相互食等事件 | “互掩”和“互食”不是所有场景都可互换；按原论文/项目采用的定义使用 |
| 互食 | mutual eclipse | 相互绕转天体之间发生的光照遮挡事件，常见于卫星系统 | 需根据天体几何与专业来源判断，避免把所有亮度变化都称为互食 |
| 彗星 | comet | 含冰、尘埃等物质的小天体；接近太阳时受加热可形成彗发和/或彗尾 | 彗尾方向受太阳辐射与太阳风等因素影响，通常不应简单说成“永远在运动方向后方” |
| 小行星 | asteroid | 主要绕太阳运行的较小天体，分布区域和轨道类型多样 | 不要把所有小行星都说成位于火星与木星之间；近地小行星等类别另有定义 |
| 小口径望远镜 | small-aperture telescope | 指口径相对较小的望远镜；适用于多种教学、监测或科学观测任务，具体能力取决于口径、探测器、天空条件和目标 | 不应仅凭“小口径”判断科研价值或观测精度 |
| 小口径望远镜观测网络 | network of small-aperture telescopes | 多个分布在不同地点的小型望远镜协同观测，可在天气、时区和目标可见性方面互补 | 是否为正式网络、成员机构、设备数量、覆盖范围和数据成果均需项目/官方来源核验 |
| 光变曲线 | light curve | 天体亮度随时间变化的记录 | 曲线本身不自动等于科学结论；须说明仪器、校准、误差与分析方法 |
| 星等 | magnitude | 描述天体亮度的对数标度；星等数值越小通常表示越亮 | 需区分视星等、绝对星等及不同波段星等 |
| 口径 | aperture | 望远镜主要集光光学元件的有效直径，影响集光能力和角分辨率等 | 实际性能也受光学质量、探测器、视宁度和处理方法影响 |
| 视场 | field of view (FOV) | 仪器一次能够覆盖的天空范围 | 视场大小取决于光学系统和探测器，不可仅凭口径判断 |
| 光污染 | light pollution | 人造光对夜空观测和生态环境造成的影响 | 讨论某地光污染程度时应有测量或可靠资料，不以主观感受冒充数据 |

## 2. 公众讲解的安全结构
- **30秒版**：先讲现象，再用一句话解释为什么有趣，最后邀请对方看图或提问。
- **2分钟版**：现象 → 如何观测/记录 → 数据能回答什么问题 → 有哪些限制。
- **专业版**：目标与几何条件 → 仪器/观测方法 → 数据质量与误差 → 推论边界 → 可追溯来源。
- 没有可靠数据时，用示意图并明确标“示意图/概念图”；不得将模拟图冒充真实观测图。
- 面对无法确定的问题，可回答：“这是个很好的问题。我不想凭印象给出错误答案，会先核对可靠资料再回复。”

## 3. 中法国际交流礼仪
- **称谓与姓名**：优先使用对方本人介绍或官方议程中的姓名、职务和机构写法；不擅自翻译或推断头衔。
- **语言选择**：先询问对方偏好中文、法语或英语；用简短句、放慢语速，必要时书面确认数字、日期和专有名词。
- **交流方式**：保持礼貌、清楚、尊重学术分歧；不把未确认的观点转述成对方正式立场。
- **名片与联系信息**：征得同意后交换或记录联系方式；只收集活动所需的最少信息。
- **摄影、录音与发布**：拍摄、录音、引用发言或发布照片前确认许可与主办方规则；不得默认公开活动即可任意发布。
- **代表身份**：社团成员只代表本人或已授权的社团口径，不代表主办方、天文台或合作机构承诺合作、数据共享或科研机会。
- **跨文化沟通**：避免刻板印象、讽刺和过度熟络；若听不清，礼貌复述确认；若术语有歧义，询问对方使用的定义。

| 小行星 | asteroid | An asteroid is a small Solar System body that orbits the Sun. |
| 彗星 | comet | A comet may develop a coma and tail as it approaches the Sun. |
| 掩星 | occultation | An occultation can cause a brief drop in a background star's brightness. |
| 小行星掩星 | asteroid occultation | An asteroid occultation is observed by recording the background star's brightness over time. |
| 互掩/互食事件 | mutual event | The exact term depends on the geometry and the convention used in the relevant study. |
| 小口径望远镜 | small-aperture telescope | Small-aperture telescopes can support education and coordinated observing, depending on the setup. |
| 观测网络 | observing network | An observing network can combine measurements from multiple sites. |
| 光变曲线 | light curve | A light curve shows how an object's brightness changes over time. |
| 观测数据 | observational data | These are observational data; interpretation requires calibration and uncertainty analysis. |

## 5. 对外事实核验清单
在展板、易拉宝、讲解稿、推文或英文邮件中出现以下内容时，逐条附来源并核验：
- 机构正式名称、机构之间的合作关系、项目/会议官方名称；
- 科研成果、观测数据、发现、数字、图表和引文；
- 人名、职务、所属单位、嘉宾身份；
- 具体观测目标、日期、地点、路径、观测成功率或设备数量；
- 图片版权、摄影者、图片是否真实观测/模拟/艺术绘制；
- 活动安排、报名方式、主办方要求、提交期限与现场权限。

没有来源时，不发布或标“需核实”。英文翻译不能把不确定事实变成肯定句。
