# event-prep｜活动筹备全流程规划

## 核心原则
1. **先算时间再谈内容。** 以今天为基准倒排，剩余天数决定输出深度：>14天=完整方案；7–14天=精简方案；3–6天=作战表（不写理念）；<3天=当日执行单（几点到、带什么、谁在哪、出事找谁）。
2. **通知里的每句话都要落到三要素：可交付物 + 负责人 + 死线。** 落不下来的进"待确认清单"，不许含糊带过。
3. **凡金额必分档：必花/建议/可选，并给砍单顺序。** 只报总数等于没做预算。
4. **凡产出物必有验收标准：尺寸/格式/分辨率/字数/张数/谁验收/何时验收。**
5. **发现通知内部矛盾**（如"下周二收稿"但活动已进行到第4天）必须显式指出，并给按最坏情况准备的方案。不许顺着通知逻辑往下写。
6. **资源不足时拒绝伪完整。** 时间、人力、预算任一明显不够时，指出做不到的事项及原因，再给最小可行版，只保人不缺席、核心交付物达标、不出安全事故。

## 工作流（按顺序执行）
- **Step0｜事实卡。** 提取活动全称、主办、我方角色、日期与每日时段、地点（含楼层门牌）、硬性要求、交付物、联系人、预算与来源、参会人群；缺失标"未明确"，不得编造。
- **Step1｜活动类型。** 判断展会摆摊、学术会议、讲座、比赛、户外观测、线上、招新、团建，可多选，调用参考清单。
- **Step2｜时间倒排。** 以今天为T，逐日列任务/产出物/负责人/卡点；标记截止、交稿、布展、开幕、合影、撤展等不可移动锚点，每个锚点前置1天缓冲，并覆盖T+7。按剩余天数选择方案深度。
- **Step3｜资源盘点。** 盘点人、钱、物、场地、外部依赖。缺项写"缺X，需在Y前解决，否则Z会黄"，附责任人和替代路径。
- **Step4｜产出物。** 分对内（方案表、值班表、物料清单、登记表）与对外（海报、易拉宝、推文、报名表、致谢），写格式、规格、死线、制作人、验收人和时间。
- **Step5｜现场执行。** 明确提前30–60分钟到场、动线站位、轮班、30秒/2分钟/专业版话术、应急预案与升级路径。
- **Step6｜会后。** 安排48小时内致谢、资料包、联系人跟进、内容产出；7天内复盘并设三个可量化指标。
- **Step7｜交付自检。** 按 references/quality-check.md 逐问核验；答"否"即修改。

## 默认输出结构（对话内直接给，严格八段）
1. **一页速览**：≤8行，含目标、时间地点、核心交付、负责人、预算区间、最大风险。
2. **需求拆解表**：通知原话｜交付物｜负责人｜死线｜验收标准。原话逐字照抄，不得意译。
3. **时间倒排表**：日期/T+n｜任务｜产出物｜负责人｜卡点/缓冲｜状态。
4. **预算分档表**：必花/建议/可选，列数量、单价、金额、依据、垫付报销；注明砍单顺序与预算上限。
5. **分工与值班表**：岗位/任务｜主责｜替补｜时段｜交接｜升级联系人。
6. **产出物清单**：对内/对外分列格式、尺寸/分辨率/字数/数量、制作人、死线、验收人和时间。
7. **现场流程与风险表**：流程按时间轴；风险按严重度排序，每条含触发条件、影响、预案、决策人。
8. **待确认与假设**：必问≤3条并附默认值；其余写假设、依据、不成立时的影响。

## 信息缺口处理
只问三类：①影响物理交付的规格（尺寸/格式/数量）；②影响倒排的真实截止时间；③权限边界（桌位、电源、入场人数、费用承担）。一次最多问3条，每条给默认值。其余采用保守假设，并在末尾写假设、依据和不成立时的影响；不得将推测写成事实。
